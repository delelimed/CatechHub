Import Ragazzi (CSV/XLSX)

Importa l'anagrafica dei ragazzi in blocco da file Excel o CSV. Riservato alla Modalità Responsabile per accelerare l'avvio dell'anno catechistico.

⚠ BETA NON FUNZIONANTE: L'Import Ragazzi (CSV/XLSX) fa parte della Modalità Responsabile, attualmente in beta non funzionante. Sarà operativo nella versione 2.0 (agosto 2027). Nella versione corrente (1.1.x) non è possibile importare anagrafiche da file.

Che cos'è

La funzione Import Ragazzi permette al Responsabile Catechistico di caricare l'anagrafica completa degli iscritti partendo da un file CSV o XLSX (Excel). Evita l'inserimento manuale uno a uno all'inizio dell'anno: prepari il foglio con i dati (nome, cognome, data nascita, classe, contatti genitori, ecc.) e li importi in pochi secondi.

Solo Modalità Responsabile. Questa funzione è accessibile solo dal Responsabile della parrocchia (dashboard parrocchiale ? Import ragazzi). I catechisti in modalità Normale o Associato non la vedono.

Formato file supportato

Il file deve avere una riga di intestazione (header) seguita dai dati. Colonne riconosciute (l'ordine non importa, si usa il nome colonna):

ColonnaObbligatoriaDescrizione
nomeSìNome del ragazzo
cognomeSìCognome del ragazzo
data_nascitaNoData nascita (YYYY-MM-DD, DD/MM/YYYY, DD-MM-YYYY)
classeNoClasse scolastica (es. 3ª elementare)
gruppoNoGruppo/percorso catechistico (es. Prima Comunione, Cresima)
telefono_madreNoTelefono madre
telefono_padreNoTelefono padre
email_genitoriNoEmail di riferimento
allergieNoAllergie/intolleranze (testo libero)
note_saluteNoNote sanitarie (cifrate con protezione campo)
uscita_autonomaNotrue/false o sì/no
noteNoNote generali del catechista

Come fare l'import

  1. Dal dashboard parrocchiale, tocca Import ragazzi
  2. Scarica il modello CSV/XLSX (tasto "Scarica modello") per avere le colonne giuste
  3. Compila il file con i dati degli iscritti (puoi usare Excel, LibreOffice, Google Sheets)
  4. Salva come .csv (UTF-8) o .xlsx
  5. In app, scegli Seleziona file e carica il tuo file
  6. L'app mostra un'anteprima con le righe valide e eventuali errori
  7. Conferma: i ragazzi vengono creati e assegnati alle classi/gruppi indicati

Gestione errori e anteprima

  • Righe con nome/cognome mancanti: saltate con avviso
  • Date non valide: ignorate (campo lasciato vuoto)
    • Gruppi/classi non esistenti: creati automaticamente se nuovo, altrimenti associati
  • Duplicati (stesso nome+cognome+data nascita): segnalati, puoi scegliere se aggiornare o saltare
  • Report finale: quanti importati, quanti saltati, quali errori

Sicurezza e privacy

  • Importazione solo locale: il file non viene mai caricato su server
  • Dati sensibili (allergie, note salute, telefoni) salvati con cifratura di campo aggiuntiva
  • Operazione registrata nel Registro Trattamenti GDPR (chi ha importato, quando, quanti record)
  • Il file originale può essere eliminato dopo l'import; i dati restano solo nel database cifrato dell'app

Template scaricabile

L'app include un modello precompilato con intestazioni corrette e qualche riga di esempio. Puoi scaricarlo in formato CSV o XLSX direttamente dalla schermata di import.
