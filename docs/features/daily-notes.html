Che cos'è

Le Note Giornaliere permettono di registrare annotazioni per ogni ragazzo in date specifiche. A differenza delle note di contatto (comunicazioni con le famiglie) o delle note generali nell'anagrafica, queste note sono legate a una giornata precisa e servono a tenere traccia di ciò che accade durante gli incontri: comportamento, partecipazione, osservazioni catechetiche, episodi particolari.

Le note giornaliere sono sincronizzate via P2P tra i catechisti dello stesso gruppo, così chi non era presente all'incontro può comunque leggere cosa è successo.

Cosa puoi fare

Scrivere note per data

Selezioni una data (di default oggi) e vedi la lista dei ragazzi del gruppo corrente. Per ognuno puoi aggiungere una nota testuale. Le note sono organizzate cronologicamente e raggruppate per data.

Filtrare e cercare

Puoi filtrare le note per data, per ragazzo, o cercare nel testo. Utile per ritrovare un'osservazione specifica o preparare un colloquio con i genitori.

Sincronizzazione P2P

Quando fai sync con un altro catechista dello stesso gruppo, le note giornaliere vengono allineate automaticamente (scope per classe, crittografia end-to-end). Così tutti i catechisti del gruppo hanno lo stesso quadro completo.

Dove si trovano

  • Nel profilo di ogni ragazzo: scheda Note giornaliere
  • Da Impostazioni ? Note giornaliere per vedere tutte le note del gruppo per data
  • Durante l'appello: accesso rapido per annotare al volo

Sicurezza e privacy

  • Cifrate AES-256-GCM nel database locale (box Hive dedicato)
  • Cifratura di campo aggiuntiva per i contenuti sensibili
  • Sync P2P solo con catechisti dello stesso gruppo (scope per classe)
  • Tracciabilità: ogni nota mostra autore, data e ora dell'ultima modifica
  • Inclusi nel backup crittografato e nella condivisione QR
